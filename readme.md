# Patterns Bakery

Patterns Bakery is designed for businesses in the food industry, such as bakeries, pastry shops, and cafés. Built with WordPress Full Site Editing (FSE), this theme allows you to customize headers, footers, templates, and global styles effortlessly. The theme includes pre-designed patterns specifically crafted for showcasing baked goods, menu offerings, feature sections, testimonials, contact page and services. Its responsive design ensures your website looks delightful and professional on all devices. Whether you are a culinary enthusiast or managing a bakery business, Patterns Bakery provides a flexible and beautiful platform to highlight your offerings and attract customers.

Primary color: `#ce873a`.

![screenshot](./screenshot.png)

## Features

- 3 hero and landing patterns
- 6 card layouts (card-1 through card-6)
- 5 archive/post-listing patterns
- Contact page pattern (page-contact)
- 2 menu navigation patterns
- 11 section layout patterns (featured sections and section titles)
- Full Site Editing (FSE) support
- Responsive design
- 64 block patterns + 15 templates + 11 template parts
- Bakery and café oriented layouts (menu showcase, hours, location)

## Requirements

- WordPress 6.6 or higher
- PHP 7.0 or higher
- Tested up to WordPress 6.7

## Development

This theme uses `@wordpress/scripts`:

```sh
npm install
npm run start    # dev mode with watch
npm run build    # production build
```
